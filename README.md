---

## What's Inside

### TensorFlow in Practice Specialization
| Course | Topics |
|--------|--------|
| Course 1 | Introduction to TensorFlow — building and training neural networks |
| Course 2 | Convolutional Neural Networks in TensorFlow — image classification |
| Course 3 | Natural Language Processing in TensorFlow — text classification, embeddings, LSTM |
| Course 4 | Sequences, Time Series and Prediction — RNNs, LSTMs, Conv1D |

### TensorFlow: Data and Deployment Specialization
| Course | Topics |
|--------|--------|
| Course 1 | Browser-based models with TensorFlow.js |
| Course 2 | Device-based models with TensorFlow Lite (Android, iOS) |
| Course 3 | Data Pipelines with TensorFlow Data Services |
| Course 4 | Advanced Deployment Scenarios |

---

## Key Concepts Covered

- Building and training **CNNs** for image recognition
- **Transfer learning** with pre-trained models (InceptionV3, MobileNet)
- **NLP pipelines** — tokenization, word embeddings, sequence models
- **LSTM** and **GRU** networks for time series forecasting
- **TensorFlow.js** for in-browser inference
- **TensorFlow Lite** for mobile/edge deployment
- Data loading with `tf.data` API

## Getting Started

```bash
git clone https://github.com/mr-haseeb/Tensorflow-Coursera.git
cd Tensorflow-Coursera
pip install tensorflow jupyter numpy matplotlib
jupyter notebook
```
